The 3-Pillar Framework of AI Automation

Before setting up any automation, understand that a successful AI workflow requires three core components running in harmony:

1. Trigger Event

Incoming event starting the process (e.g., customer email, Google Sheets row).

2. System Prompt

AI processing rules instructing ChatGPT how to transform or classify data.

3. Output Action

Delivering responses directly to the final destination (Gmail draft, Slack post).

01

Identify Tasks Worth Automating

Not every task should be automated. Focus on tasks that meet these 3 Automation Criteria:

High Frequency

Happens at least 3–5 times per week in your routine.

Structured Inputs

Uses consistent input formats like emails or form entries.

Predictable Rules

Follows clear, repeatable instructions for outputs.

02

Master the Master System Prompt Template

The secret to reliable AI automation is writing a System Prompt that forces ChatGPT to output consistent, error-free results every time:

⚠️ Customization Guide

Tags like {{Trigger.Variable}} are dynamic variables from your trigger app, and [Placeholder] are output specifications.

System Prompt Template
### ROLE & CONTEXT You are an expert Executive Assistant specializing in communications. Your goal is to review incoming customer support messages and draft professional, concise email replies. ### INPUT DATA User Name: {{Trigger.Name}} User Query: {{Trigger.Message}} Product Category: {{Trigger.Category}} ### RULES & CONSTRAINTS 1. Tone must be professional, warm, and helpful. 2. Limit your draft to under 150 words. 3. If the user asks about pricing, reference our standard refund policy (30 days money-back). 4. Do NOT invent features or make promises not listed in our documentation. ### OUTPUT FORMAT Return strictly JSON format with the following keys: { "subject": "Re: [Original Subject]", "draft_body": "[Your generated reply here]", "sentiment": "[Positive/Neutral/Urgent]" }
03

Connect ChatGPT to Your Daily Apps

To run your ChatGPT automations without manual copy-pasting, connect OpenAI’s API using a platform like Zapier or Make.com:

1

Set Up the Trigger

Select your trigger app (e.g., Google Forms) and choose the event "New Form Submission".

2

Add the ChatGPT Action Step

Add an action step, select ChatGPT / OpenAI, and authenticate with your API key.

3

Pass Dynamic Variables

Map form input fields directly into your prompt template.

3 Essential Safeguards for AI Automations

Human-in-the-Loop

Generate Drafts rather than hitting Send automatically.

Low Temperatures

Keep temperature around 0.2 to 0.3 for factual consistency.

Strict JSON Output

Prevent conversational filler by locking down schema formats.
